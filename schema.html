Prompt: 請列出eng-vocab的schema。

eng-vocab 的核心 Schema 規範包含兩大部分：「HTML <head> 專屬中繼資料結構（Metadata Schema）」 與 「資料庫實體物件結構（vocab-db.js Data Schema）」。

一、 HTML <head> 專屬中繼資料結構 (Document Metadata Schema)

所有由 eng-vocab 匯出的單檔 .html 檔案，必須在 <head> 標籤內強制注入以下 5 個 <meta> 標籤，提供入口網 index.html 進行非同步探針偵測與欄位抽取：

<!-- 格式：<meta name="[屬性名稱]" content="[欄位值]"> -->
<meta name="vocab-word" content="[目標英文單字或片語]">
<meta name="vocab-cefr" content="[CEFR 級別代碼]">
<meta name="vocab-curriculum" content="[課綱與考試階段標籤]">
<meta name="vocab-pos" content="[主要詞性]">
<meta name="vocab-def" content="[核心繁體中文釋義]">

欄位定義表 (Data Dictionary)

屬性名稱 (name) 資料型態 必填 允許值範例 說明
vocab-word String 是 nab, hesitate, volcano 目標單字，全小寫字母為原則。
vocab-cefr String (Enum) 是 A1, A2, B1, B2, C1, C2 CEFR 國際語言標準分級代碼。
vocab-curriculum String 是 國中會考核心字, 高中升學 / 新聞高頻詞 臺灣 108 課綱與升學考試階段標籤。
vocab-pos String 是 verb, noun, adjective, verb / noun 詞性，以英文縮寫或全稱呈現。
vocab-def String 是 逮捕、逮獲；搶先拿下 劍橋詞典在地繁體中文核心釋義。

二、 實體資料庫物件結構 (vocab-db.js Data Schema)

由 index.html 探測收錄、或手動維護於 vocab-db.js 的全域資料結構，型態為 JavaScript 物件陣列（JSON-compatible Array）：

JSON Schema 定義

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "VocabItem",
  "description": "eng-vocab 單字索引庫單一詞條規格",
  "type": "object",
  "properties": {
    "word": {
      "type": "string",
      "description": "英文單字，對應檔案名稱（如 nab）"
    },
    "cefr": {
      "type": "string",
      "enum": ["A1", "A2", "B1", "B2", "C1", "C2"],
      "description": "CEFR 級別"
    },
    "curriculum": {
      "type": "string",
      "description": "108 課綱階段標籤"
    },
    "pos": {
      "type": "string",
      "description": "詞性"
    },
    "defZh": {
      "type": "string",
      "description": "核心繁體中文釋義"
    },
    "path": {
      "type": "string",
      "description": "相對於 index.html 的存放路徑（例：B2/nab.html）"
    },
    "addedAt": {
      "type": "string",
      "format": "date",
      "description": "加入索引庫的日期 (YYYY-MM-DD)"
    }
  },
  "required": ["word", "cefr", "path", "defZh"]
}

實體資料範例 (vocab-db.js)

window.VOCAB_DB = [

三、 Canvas 單檔教材應用程式 (Widget App Schema)

輸出的 .html 檔案內容除具備上述 Metadata 外，必須在 <body> 內包含以下 8 大 UI/功能區塊元件：

  1. Header 區塊：單字、音標（KK + IPA）、CEFR/課綱標籤、美/英真人發音按鈕、下載 .html 與列印 A4 按鈕。
  2. Flashcard 模組：可翻轉卡片（正面英文定義，反面中文與詞形變化）。
  3. Syntax Analysis 模組：彩色底線剖析例句（藍實線主動詞、綠虛線狀語、橘點線核心搭配）＋ 句構圖例說明。
  4. Picture Story 模組：情境照片、來源出處標註、逐句朗讀按鈕與中文翻譯。
  5. Common Mistakes 模組：醒目警告色塊（拼寫地雷、語體層次、易混淆辨析）。
  6. Mini Dialogue 模組：情境短對話與逐句語音。
  7. Quick Quiz 模組：互動點擊自我檢測與即時解析。
  8. Scripts 模組：內嵌 Web Speech API 語音引擎、卡片翻轉動畫與 Blob 下載腳本。
